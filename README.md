# ElevateLabs_Task5

## Titanic Dataset - Exploratory Data Analysis
This project is part of a data analyst internship task. The goal is to explore the Titanic dataset using Python and generate insights through visual and statistical analysis.

## What I Did
- Loaded and explored the Titanic dataset
- Checked for missing values and fixed issues
- Created new features like family size
- Analyzed data using graphs like histograms, boxplots, and bar charts
- Found relationships between features like age, gender, and survival
- Used correlation heatmaps and pairplots to spot patterns
- Applied log transformation to handle skewed data
- Summarized key findings and answered EDA-related questions

## Tools Used
- Python
 - Pandas
 - Matplotlib
 - Seaborn
- Jupyter Notebook

## Key Insights

- Women had a much higher survival rate than men
- Passengers in 1st class had better chances of survival
- Most people in 3rd class did not survive
- Family size between 2 and 4 had better survival rates
- Fare values were skewed and needed log transformation
- Age and fare both showed interesting patterns with survival

## Dataset Used
The dataset used is the Titanic train set from Kaggle:
https://www.kaggle.com/competitions/titanic/data
